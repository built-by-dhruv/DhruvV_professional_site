# Dhruv Vaishnav — Portfolio

Static personal portfolio and freelance services website.

## Run locally
Open `index.html` in a browser. No build tools or server-side runtime are required.

## Deploy
The workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages on pushes to `main`.

In repository settings, ensure **Settings → Pages → Build and deployment → Source** is set to **GitHub Actions**.

## Customize
- Edit services and project summaries in `index.html`.
- Update colors, spacing and responsive styles in `styles.css`.
- Update email and social links in `index.html`.
